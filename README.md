# 🔐 Login Page

Projeto de desenvolvimento Front-End de uma tela de login com design moderno, utilizando gradientes, elementos decorativos e efeitos de interação.

O objetivo é praticar conceitos de HTML, CSS e responsividade na construção de interfaces web.

## ✨ Funcionalidades

- Layout de login centralizado.
- Campos de e-mail e senha.
- Validação básica dos campos com HTML.
- Elementos decorativos com gradientes radiais.
- Efeitos de interação nos campos e botão.
- Transições suaves.
- Layout responsivo para diferentes tamanhos de tela.
- Navegação por teclado com indicadores de foco.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3

## 📂 Estrutura do projeto

```text
login-page/
│
├── index.html
└── style.css
```

## 📚 Conceitos praticados

- Estruturação semântica com HTML.
- Flexbox.
- Posicionamento absoluto e relativo.
- Gradientes lineares e radiais.
- Pseudo-classes (`:hover`, `:focus`, `:active` e `:focus-visible`).
- Transições com CSS.
- Media Queries.
- Responsividade.
- Acessibilidade básica.

## 🎯 Objetivo

Este projeto faz parte da minha jornada de aprendizado em desenvolvimento Front-End, com foco na prática de HTML e CSS e na construção de interfaces modernas e responsivas.

## ⚠️ Observação

Esta é apenas uma interface demonstrativa. Não possui sistema de autenticação, Back-End ou armazenamento de dados.
